# Emotion Detector

## Project Description

This project is an Emotion Detector application developed using
Python and the Watson NLP library.

The application analyzes the given text and detects emotions such as:

- Anger
- Disgust
- Fear
- Joy
- Sadness

The project also includes a Flask web application that allows users
to enter text and receive the detected emotions.

## Technologies Used

- Python
- Watson NLP
- Flask
- HTML
- GitHub

## Project Structure

- `emotion_detection.py` - Emotion detection function
- `server.py` - Flask web application
- `test_emotion_detection.py` - Unit testing
- `README.md` - Project documentation
